Today was a broader class covering build pipelines, Git best practices, and industry workflows:

\* \*\*Git Cleanliness:\*\* Covered why generated build outputs (`.class`, `.JAR`) shouldn't be committed to Git, keeping the repo limited to clean source code and build configs like `pom.xml`.

\* \*\*CI/CD \& Testing:\*\* Got a high-level overview of automated testing (unit vs. integration tests) and how CI/CD pipelines run build/test steps automatically on code pushes.

\* \*\*Encoding \& Security:\*\* Briefly discussed UTF-8 vs UTF-16 trade-offs, alongside web security basics like JWT tokens and session management in Node.js.

\* \*\*Dev Advice:\*\* Touched on practical interview tips, like presenting a Proof of Concept (PoC) and communicating through difficult technical questions.
