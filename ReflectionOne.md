# Reflection – Computer Graphics & Digital Image Processing
**Date:** 06/08/2026

Today's lecture introduced the basic concepts of Computer Graphics and Digital Image Processing. I learned that Computer Graphics focuses on generating images from mathematical models, while Digital Image Processing works on enhancing or analyzing existing images. Although both fields deal with images, their objectives are quite different.

We also discussed geometric primitives such as points, lines, curves, and polygons, which serve as the foundation for creating more complex graphical objects. The lecture briefly connected these concepts with calculus, showing how mathematical ideas are important in graphics and animation.

Another topic covered was Java's graphical frameworks—AWT, Swing, and JavaFX. We were also introduced to the Event Listener Model, where applications respond to user actions like mouse clicks and keyboard input, making graphical programs interactive.

The class compared static and interactive graphics. Static graphics remain unchanged after being displayed, while interactive graphics can update based on user input through repainting. We also learned the difference between vector graphics, which can be scaled without losing quality, and raster graphics, which are pixel-based and become blurry when enlarged.

The final part of the lecture focused on Git repository access using SSH and HTTPS. I understood how SSH uses public and private key pairs for secure authentication, while HTTPS relies on credentials or access tokens. This gave me a better understanding of secure version control practices.

## Key Takeaways
- Difference between Computer Graphics and Digital Image Processing.
- Geometric primitives: points, lines, curves, and polygons.
- Java GUI frameworks: AWT, Swing, and JavaFX.
- Event Listener Model for interactive applications.
- Difference between static and interactive graphics.
- Vector graphics vs. raster graphics.
- Secure Git authentication using SSH and HTTPS.

Overall, the lecture provided a solid introduction to the course by combining graphical concepts with practical development tools such as Git and SSH. It helped build a strong foundation for the topics we will study in the coming weeks.
