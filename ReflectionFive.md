\### Java 2D and Drawing



We then moved back to Computer Graphics and discussed how a basic Java graphics window is structured.



\- \*\*JFrame\*\* acts as the main window or container.

\- \*\*JPanel\*\* is added inside the JFrame and is used as the area where we actually draw things.

\- The drawing is generally done by overriding the `paintComponent()` method.

\- We also learned why calling `super.paintComponent()` is important before drawing.

\- The `Graphics` object can be converted to \*\*Graphics2D\*\* when we need more advanced drawing features.



This cleared up some confusion I had about the relationship between the frame and the panel. The frame is basically the main container, while the panel is where the actual graphics are drawn.



\### Shapes and OOP



We also continued with Object-Oriented Programming concepts such as \*\*classes, subclasses and inheritance\*\*.



\- A subclass can extend an existing class and add its own functionality.

\- We saw how this idea can be used when creating a custom drawing panel.

\- We also worked on drawing shapes using points.

\- A rectangle can be created using two points.

\- A triangle requires three points, so choosing the coordinates properly becomes more important.



The discussion about the \*\*Triangle Inequality Theorem\*\* was also interesting because it showed that mathematics is not only theoretical here. It can actually help us check whether the points we choose can form a valid triangle.
